The purpose of this file is to document the process of working with the art assets (managing file types, compressions, making sprite sheets, etc.). This will make it easier to reproduce similar results, adjust small details like compression or add extra spacing later, and prevent wasting time refiguring out how to do it :)

https://www.imagemagick.org/
I am using image magick software to achieve all of this (and yes this is my first time using it so I am sure I will get better at it as I go).

// Game board
magick gameBoard.png -resize 16% gameBoard.jpg

// Enemy Sheets:
magick montage *).png -resize 20% -mode Concatenate -tile 1x2 montageBuffer.jpg
magick montage montageBuffer*.jpg -mode Concatenate -tile x1 finalMontage.jpg

// Threshold sheets
magick montage *.png -resize 20% -mode Concatenate -tile 1x2 montageBuffer.jpg 
magick montage montageBuffer-*.jpg -mode Concatenate -tile x1 thresholdSheets.jpg 

// Breaches
magick montage *.png -resize 120x168 -mode Concatenate -tile x1 Breaches.jpg

// Permanent Breach token
magick *.png -resize 15% * PermanentBreach.jpg

// First Mate token
magick montage *.png -resize 20% -mode Concatenate -tile x1 FirstMate.png

// Damage token was just converted to png and moved 
// (already small and compression made it look worse and increased file size)
magick *.png DamageCounter.png

// Clear Water cards
magick montage *.png -resize 120x168 -mode Concatenate -tile 10x3 WaterDeck.jpg

// Dice!
// I did each die one by one, actually wasn't that bad. I thought about making a command that did all of the same type at the same time but I knew I would get distracted and spend too much time trying to figure out the perfect command so instead I did the more verbose method but didnt get distracted
// Ex: Basic die
// First name each side using subregions
magick Basic.png[500x500+0+0] BasicBlank.png
magick Basic.png[500x500+500+500] BasicBreach.png
magick Basic.png[500x500+500+1000] BasicWater.png
magick Basic.png[500x500+1000+1000] BasicCannon.png

// Now assemble them into one row, in order of associated value (1,2,..., 6)
magick montage B*Water.png B*Breach.png B*Blank.png B*Blank.png B*Blank.png B*Cannon.png -mode Concatenate -tile 6x1 BasicRow.png
